
# Google Cloud Platform

Google Cloud Platform (GCP) is a commercial cloud service supported by CU Research Computing (CURC) in collaboration with CU Anschutz. CURC can provision GCP accounts for University of Colorado affiliates. Account holders will manage their own applications, data, and use of GCP services. Billing for GCP services is done via SpeedTypes. If you are looking to get a new GCP account or have questions about an existing account, email [rc-help@colorado.edu](mailto:rc-help@colorado.edu)
